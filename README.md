# 300 Traces Template

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Annoymity00999/300-traces-template)

一个可替换内容的双语阅读档案模板：随机遇见、分类阅读、本机足迹与时间层媒体。

- 用 **Use this template** 复制，或点上方按钮部署。
- 替换 `app/data/trace-data-*.json`、`app/page-copy.ts` 与 `public/` 中的资料。
- 本地检查：`npm install && npm test && npm run build:vercel`。

它先作为静态网站运行；需要投稿、审核或跨设备同步时，再自行配置后端。AI 协作请先阅读 `docs/AI_REPLICATION_GUIDE_300_TRACES_2026-09-11.md`。
