# 300条痕迹：零基础复刻指南

版本：2026-09-11

适合谁：没有写过代码、不了解 Vercel、也不了解本项目背景的人。
你需要的只有：电脑、这个 ZIP 包、一个能处理文件的 GPT/Codex，以及一个自己登录的 Vercel 账户。

## 先说结论

这个包可以让一个完全不了解项目的人复刻出一个**自己的、可打开的阅读网站**；最轻的版本不需要数据库、不需要账号系统、不需要管理员密码。

最适合新手的是先复刻“静态阅读版”：随机遇见、文章分类、双语、图片、声音入口、个人浏览器足迹和二维码都保留；私密反馈、跨设备恢复、审核队列等需要服务端秘密配置的能力先不打开。

## 路线 A：最推荐，交给 GPT/Codex 完成

### 你只要做五件事

1. 下载并解压 `300-traces-replication-kit-2026-09-11.zip`；不要先改里面的文件。
2. 打开一个新的 Codex 或 ChatGPT 编程任务，把解压后的整个文件夹提供给它。
3. 把下面这段话完整发送给它。
4. 当它提示需要登录 Vercel 时，你自己在浏览器完成登录；不要把密码、验证码或 token 发给 AI。
5. 它给出新网址后，用手机打开一次，确认阅读入口和原文链接正常。

### 可直接复制给 AI 的说明

```text
我完全不熟悉代码。请把这个 300 Traces 复刻包变成一个可公开访问的静态阅读网站。

先阅读：
1. 零基础复刻指南_300条痕迹_2026-09-11.md
2. START_HERE.md
3. replication-kit-manifest-2026-09-11.json

请只做以下事情：
- 保留“痕迹 / 遇见 / 接住”的阅读体验，不把它改成任务、社交或 SaaS 网站；
- 先在本机启动并检查：开屏、随机遇见、三类筛选、打开原文、阅读足迹、语言切换、日期图片和外链；
- 只替换我明确提供的文字、链接、图片或 JSON 数据；不编造文章、作者、译文或来源；
- 先部署静态阅读版到我自己的 Vercel 账户；
- 私密反馈、审核、跨设备进度等服务端功能先关闭或显示为未启用，不要索取或编造密钥；
- 发布前运行项目已有测试和生产构建；
- 最后只告诉我：新网址、哪些内容已保留、哪些动态功能没有启用、以及我下一步只需做什么。

不要删除带有 “2” 的旧文件，不要公开任何密码、token、个人进度或私密资料。
```

## 路线 B：先完全不改内容，只做一个自己的副本

如果只是想让网站先跑起来，可以告诉 AI：

> “不要修改数据和文案，先原样部署一个可访问副本。”

这条路线最快。它得到的是当前设计的可运行副本，但不会继承原网站的私密资料、审核钥匙、参与者数据或域名。

## 以后会更简单：GitHub 模板按钮

当原作者完成 GitHub 模板仓库发布后，陌生人甚至不必下载 ZIP：点击 **Use this template** 或 **Deploy with Vercel**，登录自己的账户，就能得到自己的静态阅读副本。具体发布安全清单见 `GitHub模板发布清单_300条痕迹_2026-09-11.md`；在模板仓库尚未公开前，仍使用本指南的“路线 A”。

## 路线 C：之后再替换成自己的项目

当静态副本已经能打开，再分四次替换，不要一次改完：

1. **文章资料**：改 `app/data/trace-data-*.json`；每条至少保留 `sourceId`、类型、标题/摘录和原文链接。
2. **网站语言**：改 `app/page-copy.ts`；中文和英文应表达同一件事。
3. **日期材料**：改 `app/data/period-*.ts` 及 `public/period-images`；每张图片、声音和事件都应保留来源链接。
4. **视觉与入口**：最后才改 `app/globals.css`、海面影像或色彩；每改一次先用手机预览。

每次只改一类，部署后检查一次；这样出错时知道是哪个改动造成的。

## 你不需要理解的部分

以下内容由 AI 处理即可：安装依赖、启动本地预览、运行测试、生产构建、Vercel 发布、缓存刷新、手机尺寸检查和错误定位。

你不需要学习 React、TypeScript、API、Vite 或 Git 才能使用这个包；你真正需要做的是判断内容、画面、链接和是否发布。

## 两种能力的边界

| 你想要的结果 | 静态阅读版是否可用 | 是否需要额外服务/密钥 |
| --- | --- | --- |
| 随机遇见、类型筛选、原文链接、双语、图片、时间层 | 可以 | 不需要 |
| 同一台设备保存阅读足迹 | 可以 | 不需要，浏览器本地保存 |
| 个人足迹导出 | 可以 | 不需要 |
| 二维码指向新网站 | 可以 | 不需要 |
| 私密评分/反馈真正写入服务器 | 需要配置 | 需要自己的服务端环境变量 |
| 跨设备恢复阅读记录 | 需要配置 | 需要自己的服务端存储 |
| 投稿审核、公开索引、多人互动 | 需要配置 | 需要反滥用、隐私与维护决定 |

## 绝对不要做的事

- 不把任何密码、Vercel token、管理员钥匙或验证码发给 AI 或放进网页文件。
- 不把压缩包里的旧文件、`* 2.*` 文件或不明媒体随意删除；它们可能是备份。
- 不把他人的原文全文、未经许可的音视频或私人资料直接放进公开网站。
- 不在没有测试的情况下同时大改数据、样式和部署设置。

## 一次发布后的最低检查

- 用手机打开新网址，不是只在电脑看。
- 点击“遇见一条未读痕迹”，确认出现编号、类型、标题/摘录和原文入口。
- 切换中文/英文，确认没有混乱或空白。
- 换一个日期，确认图片/声音失败时页面仍可继续阅读。
- 打开项目材料，确认其中没有密码、私人姓名、阅读记录或私密投稿。

## 如果只记住一句话

**把整个包交给 AI，让它先部署静态阅读版；你只负责登录、提供自己的内容，并决定是否发布。**
