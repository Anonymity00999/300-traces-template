# 300 Traces · 设计契约

2026-09-15，当前交接阶段。用途：让不熟悉背景的开发者或 AI 在不恢复旧功能的前提下继续维护。

## 整体结构

静态 HTML → React/Vite 阅读器 → 同源服务端 API → 私有 Blob。

静态阅读不等待服务端；核心294条直接包含在前端构建中，同时输出独立JSON便于导入。外部影像、声音与原文独立加载，失败只影响自身。正式入口统一，克隆者使用自己的域名和自己的存储，不能共享原作者凭证。

| 编号 / 专业概念 | 当前要求与验收标准 |
| --- | --- |
| R01 · 渐进披露 Progressive disclosure | 主影像在上，阅读层在下；友情链接、材料出口收纳，不打断主要体验。 |
| R02 · 稳定内容身份 Stable content identity | 294条，三种类型；sourceId唯一，显示编号可变，不能因此丢失进度。 |
| R03 · 无早期重复抽样 Unread-first sampling | 先抽未遇见者；候选耗尽才重访；连续点击、单条和空集均有确定行为。 |
| R04 · 时间分层 Temporal indexing | 2026-03-16—22按日组织图片、文章、事件、声音，均保留来源；日期切换不停止正在播放的声音。 |
| R05 · 双语对应 Locale parity | EN默认；中文和英文标题/动作对应，保留原始来源，禁止虚构翻译与全文。 |
| R06 · 匿名凭证 Pseudonymous recovery code | 用户码是取回凭证，不是实名账号；私密保存，持有码者可能取回该码的数据，不能放进公共材料。 |
| R07 · 数据最小化 Data minimisation | 个人导出只有userCode、browsingData、readingTime、witnesses；不带邮箱、审核状态、抓取日志或其他人的投稿。 |
| R08 · 打开时间 Opening timestamps | 只记录首次/最近打开内容的日期时间（UTC ISO 8601）；不记录停留时长、不声称外站阅读完毕；旧时间缺失留空。 |
| R09 · 归属隔离 Ownership isolation | 本机记录必须匹配当前码；云端同样匹配；无法确认归属的旧本机见证不自动纳入。切换码同时替换时间与浏览集合。 |
| R10 · 参与边界 Participation boundary | 当前星级反馈为独立通道，留言/邮箱选填；不恢复公开留言、直接音视频上传或见证投稿表单；已有见证仍可个人导出。 |
| R11 · 媒体路由 Media routing | EN主影像默认Vimeo；ZH默认Bilibili外链；用户可切换；Bilibili未补链接时不能伪造可播放。两份刮擦彩蛋亦预留外链；揭晓其中一项后，同一存档码只呈现该项，刷新与恢复沿用选择，进度只计一份彩蛋。此为体验规则，不是身份验证或防绕过措施。 |
| R12 · 低干扰工具 Quiet utilities | 二维码、存档、指令、反馈不过度突出；指令库仅从指令内部进入，观影房不混入主作品。 |
| R13 · 材料化视觉 Material-led visual language | 暖灰阅读面、克制海蓝、局部蜡感，完整图片、不遮挡文字；海面影像留足下方距离，分隔原则一条、文字不贴线。 |
| R14 · 可降级动态 Graceful motion degradation | 八字时钟持续变速/倒退，hover局部漩涡；不产生闪光、整体放大或输入遮挡；减少动态、离屏及WebGL失效时降级。 |
| R15 · 跨设备适配 Responsive parity | 至少检查390px手机与1280px桌面；无横向溢出，日期和抽取按钮不改变父区域缩放，触控不依赖hover。 |
| R16 · 内容治理 Content governance | 未经明确授权不加解释、备注或工作过程文案；删除中英同步，旧远程配置不得覆盖回来；删除空容器。 |
| R17 · 可恢复交付 Reproducible delivery | 锁定依赖，源文件/素材清单/校验和/测试/构建齐备；私密数据不随复制转移；失败返回局部状态，不假报同步成功。 |
| R18 · 证据分级 Evidence-based acceptance | 本机构建、浏览器检查、公开域名探测与大陆实网分别报告；HTTP200不等于所有功能完好。 |

## 存储范围审计

改动前：本机分别保存浏览ID和未归属投稿历史；云进度只有ID与更新时间；导出没有用户码，内容日期实际是发表日期，并非阅读时间。改动后：按码保存浏览集合与打开时间，导出加入用户码和严格筛选的本人见证。时间层“呈现过”和“打开过”仍是不同信号；呈现不生成打开时间。

本轮没有删除服务器历史投稿，也没有更改独立星级反馈的邮箱字段。反馈递送队列、语言选择、开屏状态属于功能配置，不混入“足迹与见证”；云厂商访问日志由托管方管理，不声称整台服务器只留四个字段。无新行为指纹、IP或停留时长采集。

## 维护顺序

先改对应数据/模块 → 运行测试和构建 → 对照手机/桌面交互 → 检查公开包隐私 → 发布一次 → 核对正式版本。保留上一部署以便回退。测试内容不得冒充真实观众数据；不要将密钥、`.env`、本机路径和原始聊天上传公开仓库。
