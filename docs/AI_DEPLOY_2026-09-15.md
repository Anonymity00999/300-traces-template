## Local reproduction

1. Use Node 24.x (verified with 24.12.0), npm, an empty target directory. Do not overwrite another project.
2. Run `npm ci`, `npm test`, `npm run build`, `npm run verify:release`.
3. Run `npm run start -- --port 5186`. Test `/`, `/instruction-library`, `/watch-room`. Static preview has no API; local progress still works, remote functions are unavailable, not successful.
4. Check language parity, random article/image changes, dated sources, no parent zoom, main video routing, scratch choices, a feedback form without sending, anonymous pass and personal JSON export. Check 390px and 1280px, keyboard and reduced motion.

## Vercel

Import the repository into the recipient's own account; `vercel.json` selects `npm run build:vercel` and `dist`. No domain, team ID or password is inherited. Set `VITE_PUBLIC_ARCHIVE_URL` to the recipient's domain after it is available. Use same-origin APIs (leave `VITE_ARCHIVE_API_BASE` empty). Never route a clone to the original author's API.

Static reading needs no database. For cloud progress, legacy witness retrieval and feedback, provision a **private Vercel Blob store** in the recipient's project and attach its server-only `BLOB_READ_WRITE_TOKEN`; set a new high-entropy server-only `ARCHIVE_ADMIN_KEY` for retained maintenance endpoints. Never put secrets in VITE-prefixed values or Git. Rebuild after public URL changes. Domain/DNS, provider signup and billing remain the recipient's decisions; do not silently purchase services.

The source includes legacy API compatibility so old records can be retrieved; disabled reference/upload/editor routes are not a request to re-enable them. No audience submissions, passes, feedback or private settings ship in this package.

## Acceptance and honest limits

Record build/test counts and browser checks, not just deployment success. A local preview cannot prove Mainland/WeChat reachability. Test the new production domain on actual target networks; unavailable external audio/video must fail locally with a source link. Old reading dates remain unknown. Personal exports contain recovery codes and must not be published with the source. Cloud simultaneous updates still use non-transactional Blob merge; large-scale use needs an indexed transactional store. Do not claim all features work without storage configuration.
